# Real Estate Investment Analysis Tool

A financial analysis tool built with Streamlit for real estate investors.  
It calculates:

- Mortgage payments
- Amortization schedules
- Net operating income
- Cap rate
- Cash-on-cash return
- NPV and IRR
- Sensitivity analysis (rent & interest rate)
- Charts and CSV exports
